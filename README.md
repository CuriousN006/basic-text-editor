# Basic Text Editor

설치 없이 Edge 또는 Chrome에서 실행하는 오프라인 리치 텍스트 편집기입니다.

Word와 비슷한 방식으로 글을 편집하고, 네이버 카페 같은 웹 편집기에 서식 있는 상태로 복사하는 용도로 만들었습니다.

## 주요 기능

- 단일 `index.html` 파일로 오프라인 실행
- 외부 라이브러리, 서버, 로그인, Node.js 불필요
- 마크다운, HTML, 일반 텍스트 파일 불러오기
- HTML, 마크다운 및 Microsoft Word용 DOCX 저장 (첫 저장 후 같은 파일 업데이트)
- 입력을 잠시 멈추면 브라우저에 복구용 초안을 자동 저장하고, 파일에 기록된 것을 확인한 뒤에만 초안 정리
- 제목, 굵게, 기울임, 밑줄, 취소선, 좌·중·우 정렬, 목록, 인용문, 코드 블록
- 커서 위치와 입력 상태에 맞춘 서식 버튼 및 문단 종류 표시
- 글자를 드래그하면 선택 영역 가까이에 나타나는 굵게·기울임·밑줄·취소선 미니 도구막대
- Word처럼 격자 또는 행·열 숫자로 기본 서식 없는 표만 삽입하고 `Tab`으로 칸 이동·새 행 추가
- 빈 줄을 편집 가능한 빈 문단으로 보존
- 선택한 글자 위에 URL을 붙여 넣어 링크 생성
- 링크와 팝업 사이의 연결 영역 및 클릭·주소 복사가 가능한 링크 미리보기
- Word처럼 Ctrl+클릭으로 링크 열기
- 드래그한 글자를 Ctrl+F와 Ctrl+H의 찾을 내용에 자동 입력하고 문단·줄바꿈은 `^p`·`^l`로 변환
- 서식 경계를 가로지르는 글자도 찾아 굵게·기울임·밑줄·취소선을 적용하거나 제거할 수 있는 찾아 바꾸기
- 찾을 내용을 입력하면 바로 보이는 전체 일치 개수와 현재 위치 (`3 / 12`)
- 찾기 칸에서 `Enter`를 계속 눌러 다음 일치로 이동, `Shift+Enter`로 이전 일치로 이동
- 본문을 편집하는 중에는 `F3` · `Shift+F3` (`Ctrl+G` · `Ctrl+Shift+G`도 같음)
- 끄면 영문 대소문자를 같은 글자로 보는 대소문자 구분 선택
- 몇 개를 바꿨든 `Ctrl+Z` 한 번으로 되돌아가는 모두 바꾸기
- Word식 특수기호 치환 (`^p`, `^l`, `^t`, `^^`)
- `Ctrl+V`는 굵게·기울임·밑줄·취소선·하이퍼링크를 유지하고 줄 구조는 다시 계산해 붙여넣기 (글꼴·글자 크기·색 같은 외부 서식은 가져오지 않음)
- `Ctrl+Shift+V`는 서식 없이 글자만 붙여넣기
- 받침에 맞춘 한국어 조사 자동 교정
- 네이버 카페에서 줄·빈 줄과 표 테두리가 유지되도록 독립 블록과 인라인 표 서식으로 변환해 리치 텍스트 복사

## 실행 방법

1. 저장소에서 `index.html`을 다운로드합니다.
2. 파일을 더블클릭합니다.
3. 연결 프로그램을 묻는 경우 Edge 또는 Chrome을 선택합니다.

자세한 내용은 [사용법](사용법.md)을 참고하세요.

## 네이버 카페에 붙여 넣기

1. 문서를 작성하거나 파일을 불러옵니다.
2. **전체 서식 복사**를 누릅니다.
3. 네이버 카페 글쓰기 창에서 `Ctrl+V`를 누릅니다.

네이버 카페가 허용하지 않는 일부 서식은 붙여넣기 과정에서 제거될 수 있습니다.
